# atsumate (集まて)

集まりごとの企画から日程調整、店選び、予約、連絡、役割分担、立替管理、AI傾斜割り勘、精算までを一気通貫でフルフォローする次世代イベントプラットフォーム。

自前で構築した **`langgraph_sample` (Python / FastAPI / LangGraph / Ollama / Vision API / Web Search)** をAIエージェント基盤としてフル活用し、「**AIが副幹事（Co-Organizer）として伴走する**」体験を実現します。

## 🎯 幹事の体験はどう変わるか？（主要機能）

1. **日程調整の自動化**:
   - 「来月の金土夜」でAIが候補日を一括生成。主賓（★キーパーソン）が来られる日を最優先し、「開始を30分遅らせれば全員参加できる」などの時間調整も提案。
2. **お店選びのプレッシャー解消**:
   - Web検索ツールで条件に合う店舗を3〜4軒ピックアップし、画面内でワンタップ多数決投票。アレルギーや禁煙希望も自動考慮。
3. **予約忘れ・キャンセル料の完全防止**:
   - 予約サイトの備考欄コピペ文や電話予約カンペを自動生成。予約スクショを撮るだけでVision APIが自動取り込み。キャンセル料発生前日に未確定者へ確認アラート。
4. **連絡・コミュニケーションのストレスゼロ**:
   - LINEグループ不要の専用ボード。場所・時間・会費は最上部に常時ピン留め。常駐AIコンシェルジュが道案内や「30分遅刻」の連絡を自動対応＆出欠ステータス同期。終了後は高画質アルバムで写真共有。
5. **レシート撮影 & 傾斜割り勘**:
   - レシート写真を撮るだけで品目を自動分類（お酒/食事）。「飲む人多め、遅刻者半額」などの指示から最小送金回数（Debt Simplification）でPayPay精算リンクを自動生成。
6. **幹事も参加者もストレスフリー**:
   - 幹事のみログイン。参加者は招待URLから名前入力だけで回答可能。LINE、メール、カレンダー、Push通知に対応。
